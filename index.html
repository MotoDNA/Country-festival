축제 달력은

한국관광공사가 공공데이터포털(TourAPI)로 공개하는 전국 축제·행사 정보를 달력, 지도, 내 주변 세 가지 방식으로 보여주는 무료 서비스입니다. 페이지를 열 때마다 최신 데이터를 받아오며, 사진·기간·장소·문의처와 관광공사 소개글을 함께 제공합니다.

이번 주말에 갈 곳을 찾을 때는 내 주변에서 위치를 잡고 기간을 이번 주말로 두세요. 여행 계획이라면 달력에서 월을 넘기며 지역을 고르면 됩니다. 외국인 방문객은 오른쪽 위 EN으로 영문 데이터를 볼 수 있습니다.

축제 정보는 얼마나 정확한가요?
지자체와 한국관광공사가 등록한 공식 정보를 그대로 보여줍니다. 다만 날씨·현장 사정으로 일정이 바뀔 수 있으니 방문 전 상세 화면의 문의처나 공식 홈페이지로 확인하세요.
사진이 없는 축제도 있나요?
관광공사에 사진이 등록되지 않은 행사는 회색 카드로 표시됩니다. 정보 자체는 동일하게 제공됩니다.
운영 주체는 누구인가요?
디엔에이랩스가 만든 개인 프로젝트이며 광고나 회원가입 없이 무료로 제공됩니다. 데이터 출처: 한국관광공사 TourAPI 4.0 · 지도: 카카오맵.
데이터 한국관광공사 TourAPI · 지도 카카오맵
축제 정보는 주최 측 사정으로 변경될 수 있습니다.

    API 키 설정

    두 개의 키를 넣으면 실제 데이터와 지도가 동작해요. 이 브라우저에만 저장됩니다. (사이트를 공개할 때는 파일 위쪽 CONFIG에 직접 적어두세요.)

    data.go.kr → "한국관광공사_국문 관광정보 서비스_GW" 활용신청 → 마이페이지에서 일반 인증키(Decoding) 복사
    앱 설정 → 카카오맵 사용 설정 ON, 플랫폼 → Web 에 이 사이트 주소를 등록해야 지도가 뜹니다.
    키가 아직 없다면
    1. 공공데이터포털 회원가입 → 검색창에 한국관광공사_국문 관광정보 서비스_GW → 활용신청
    2. Kakao Developers → 내 애플리케이션 → 애플리케이션 추가 → 앱 키의 JavaScript 키
    3. 같은 화면에서 카카오맵 → 사용 설정 ON, 플랫폼 → Web → 사이트 도메인에 이 페이지 주소 등록
